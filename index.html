失敗図書館（Failure Library）／制定日：2026年9月23日

失敗図書館（以下「本アプリ」）は、受験でうまくいかなかった経験と、その後どう立て直したかを匿名で共有するアプリです。 本アプリは、利用者の個人情報を可能なかぎり集めない方針で作られています。 本ポリシーでは、何を集め、何を集めないのかを具体的に記載します。

1. 集めない情報

本アプリは、以下の情報を一切取得しません。

  • 氏名、住所、電話番号
  • メールアドレス（アカウント作成に不要です）
  • 生年月日、性別
  • 位置情報
  • 連絡先（アドレス帳）、写真、カメラ、マイク
  • 広告識別子（IDFA など）
  • 学校名、通っている塾・予備校の情報

アカウント登録にメールアドレスもパスワードも必要ありません。SNS 連携もありません。

2. 集める情報

情報内容目的
ニックネーム利用者が自分で決める表示名投稿の管理（本名を入力しないよう案内しています）
受験のタイプ大学受験 / 高校受験 / その他 の3択自分に近い体験談を表示するため
投稿内容「失敗」と「その後」の本文、カテゴリ、科目アプリ内で他の利用者に表示するため
購入状態有料版を購入済みかどうか購入した機能を利用可能にするため
利用者IDアプリが自動で発行するランダムな文字列（UUID）自分の投稿を判別するため

利用者IDは、氏名やメールアドレスとは結びついていません。端末内の安全な領域（iOS のキーチェーン）に保存され、 外部に送信されるのはサーバーへの問い合わせ時のみです。

3. 投稿の匿名性

図書館に並ぶ投稿には、投稿者のニックネームは表示されません。 表示されるのはカテゴリ（模試・定期テスト・得意科目・苦手科目）と科目、本文だけです。 誰が書いたかは他の利用者から分かりません。

4. お子さまの安全のための仕組み

本アプリは主に中学生・高校生の利用を想定しており、次の仕組みを設けています。

  • メールアドレス登録が不要 — 個人を特定できる情報を最初から集めません
  • 禁止ワードの自動フィルター — 誹謗中傷にあたる語を含む投稿は、送信前にブロックされます
  • 投稿の遅延表示 — 投稿は30分後に公開されます。勢いで書いたものを見直す時間を設けるためです
  • 通報による自動非表示 — 3件の通報を受けた投稿は自動的に非表示になります
  • 匿名表示 — 投稿に投稿者名は出ません
  • メッセージ機能なし — 利用者どうしが直接やり取りする手段はありません

13歳未満のお子さまの利用は想定していません。保護者の方は、お子さまの利用状況についてご確認ください。

5. 情報の保存先と第三者提供

取得した情報は、以下のサービス上に保存・処理されます。これらの事業者以外に、情報を販売・提供することはありません。

事業者用途所在
Supabase Inc.投稿とニックネームの保管シンガポール（Amazon Web Services）
RevenueCat, Inc.購入状態の管理米国
Apple Inc.アプリ内課金の決済処理米国

決済のためのクレジットカード情報は Apple が処理し、本アプリが受け取ることはありません。

本アプリは、アクセス解析ツールや広告配信ツール（Google Analytics、Firebase Analytics、広告SDK など）を 一切組み込んでいません。

法令に基づく開示請求があった場合を除き、第三者に情報を提供することはありません。

6. 情報の削除

投稿の削除やアカウントの削除をご希望の場合は、下記の連絡先までご連絡ください。 ご本人からのご依頼であることを確認のうえ、速やかに削除いたします。

アプリを削除すると、端末内に保存された利用者IDも消えます。この場合、同じアカウントには戻れなくなります （サーバー上の投稿は残るため、削除をご希望の場合は上記の連絡先までお知らせください）。

7. 情報の保存期間

投稿は、削除のご依頼があるまで、または通報により非表示になるまで保存されます。 ニックネームと受験タイプは、アカウント削除のご依頼を受けるまで保存されます。

8. 本ポリシーの変更

本ポリシーを変更する場合は、本ページ上で改定日とともに公開します。 重要な変更の場合は、アプリ内でもお知らせします。
